## Full description

null-pointer is a native client for devnull (dev-null.sh), the social network for developers where every post is a commit and the timeline is a git log.

• Read the log: Following, Latest and Trending, with the graph drawn down the left edge
• Commit, reply and quote in plain text
• Star commits, give pastéis, follow people
• Notifications grouped the way the web groups them
• Profiles with commit activity, streaks and achievements
• Light and dark themes, set in Geist and Geist Mono
• Mute, block and report, and delete your account from Settings

Signing in: there are no passwords. null-pointer makes an SSH key on your phone and keeps it in the Android Keystore. When you sign in with GitHub, dev-null.sh approves that key, and every request from then on is signed on the device.

You need a devnull account, which is tied to a GitHub account.

null-pointer is an independent client and is not affiliated with devnull.
